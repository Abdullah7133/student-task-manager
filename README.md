# Student Task Manager Application

A simple web application to manage daily student tasks and assignments[cite: 4].

## Features
- **Task Creation:** Users can add new tasks with a title and a detailed description[cite: 1, 3].
- **Completion Status:** Tasks can be toggled between active and completed states using a checkbox[cite: 2]. Completed tasks are visually distinguished with a strikethrough and reduced opacity[cite: 2].
- **Data Persistence:** Tasks and their completion statuses are saved locally in the browser using `localStorage`, ensuring data is retained upon page refresh[cite: 2].
- **Task Search & Filtering:** Users can dynamically search for specific tasks by keyword[cite: 1].
- **Responsive Design:** The application layout adapts for mobile screens[cite: 1, 6].

## Technologies
- HTML5 for structure[cite: 1, 4]
- CSS3 for styling[cite: 1, 4]
- Vanilla JavaScript for dynamic DOM manipulation and logic[cite: 1, 4]

## How to Run (Setup)
1. Clone or download the repository to your local machine[cite: 1].
2. Open `index.html` in any web browser to view the application[cite: 4]. No local server is required.
